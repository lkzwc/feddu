# 微信登录
微信登录基本方式会有四种、这一期我们给大家讲讲
* 微信开放平台 (备案、个人申请、门槛比较高)
* 微信服务号（300元）
* 微信小程序 (300元)
* 微信公众号

## 实现过程
> 本来网站最开始是使用服务号的方式实现的，但是后期又考虑要花钱，且就获取个用户信息，好像作用也不大，于是乎就使用微信公众号去实现了，这里我们简单提一下登录的原理，首先前端给出公众号的二维码，然后生成一个随机的验证码，用户向公众号发送消息，公众号收到消息之后通知，这就是基本的流程
