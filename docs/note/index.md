# 📚 学习笔记

欢迎来到我的学习笔记区域！这里记录了我在前端开发路上的学习心得和技术总结。

## 🎯 学习目标

通过系统性的学习和实践，掌握现代前端开发的核心技术栈，包括但不限于：

- **基础知识**：JavaScript 核心概念、浏览器原理
- **框架技术**：React、Vue 等主流框架
- **工程化**：构建工具、性能优化、代码规范
- **容器化**：Docker、Kubernetes 等云原生技术

## 📖 内容分类

### 🔧 基础技术 (Basic)
JavaScript 基础知识，包括数据类型、闭包、原型链、异步编程等核心概念。

### 🌐 浏览器技术 (Chrome)
浏览器架构、渲染原理、性能优化、垃圾回收等浏览器相关知识。

### 🎨 设计模式 (Design)
常用设计模式的理论与实践，提升代码质量和可维护性。

### 📦 容器化技术 (Docker & K8s)
Docker 容器化部署和 Kubernetes 集群管理相关知识。

### ⚙️ 工程化 (Engineering)
前端工程化实践，包括构建工具、热更新、安全防护等。

### ⚛️ React 生态
React 框架深入学习，包括 Fiber 架构、Hooks、性能优化等。

### 💚 Vue 生态
Vue 框架相关知识和最佳实践。

### 📚 源码阅读 & 实现
优秀开源项目源码分析和核心功能手写实现。
